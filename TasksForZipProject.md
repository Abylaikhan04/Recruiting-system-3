# Что есть в ZIP-проекте, чего нет у нас

> ZIP — это Figma-дизайн проект (только фронтенд, mockData). Наш проект — fullstack с реальным backend.
> Этот файл: фичи из ZIP которые стоит перенести к нам.

---

## 🗓️ 1. Календарный вид для встреч (Meetings → Calendar view)
**Что есть в ZIP:** Переключатель «Список / Календарь» на странице встреч. Мини-сетка месяца с отметками дней.
**У нас:** Только список.
**Как решить:** Добавить `view` state (`list | calendar`) в `Meetings.tsx`. В календарном режиме рендерить сетку дней месяца, подсвечивать дни со встречами.

---

## 🚨 2. Баннер «Ближайшая встреча» (Next meeting alert)
**Что есть в ZIP:** Вверху страницы встреч цветной баннер — красный если встреча через < 2 часа, янтарный если позже.
**У нас:** Нет.
**Как решить:** В `Meetings.tsx` найти ближайшую предстоящую встречу, показать баннер с таймером.

---

## ☑️ 3. Массовый выбор кандидатов + пакетный AI-анализ
**Что есть в ZIP:** Чекбоксы в строках таблицы кандидатов. Кнопка «Анализировать выбранных» (AI).
**У нас:** Только одиночный AI-анализ из страницы кандидата.
**Как решить:** Добавить `selectedIds[]` state в `Candidates.tsx`, чекбокс в каждой строке, кнопку bulk-analyze которая шлёт POST на `/api/candidates/:id/analyze` для каждого выбранного.

---

## ✏️ 4. Inline редактирование этапа в таблице кандидатов
**Что есть в ZIP:** Клик по бейджу этапа прямо в таблице открывает dropdown со списком этапов — без перехода на страницу кандидата.
**У нас:** Нужно зайти на страницу кандидата.
**Как решить:** В строке таблицы `Candidates.tsx` добавить `editingStage` state. По клику на бейдж — показывать select/dropdown рядом.

---

## 👤 5. Дополнительные поля кандидата
**Что есть в ZIP:** `salary`, `experience`, `education`, `skills[]`, `age`, `organization`, `telegram`, `whatsapp`, `rejectionReason`, `photo`, `vacancyId`
**У нас:** Нет большинства из них.
**Как решить:**
- Backend: `ALTER TABLE candidates ADD COLUMN salary TEXT, experience TEXT, education TEXT, skills TEXT, age INT, organization TEXT, telegram TEXT, whatsapp TEXT, rejection_reason TEXT, photo_url TEXT` в `initDb()` в `server.js`
- Frontend: Добавить поля в форму создания кандидата (`Candidates.tsx`) и в карточку кандидата (`CandidateDetail.tsx`)

---

## 🔔 6. Счётчик уведомлений в шапке (Notification bell)
**Что есть в ZIP:** Колокольчик в Header с красным бейджем-счётчиком (`notificationCount`).
**У нас:** Нет.
**Как решить:** В `Layout.tsx` добавить иконку Bell с бейджем. Считать кол-во из pending заявок + предстоящих встреч сегодня.

---

## 📋 7. Дополнительные поля вакансии
**Что есть в ZIP:** `priority` (low/medium/high/urgent), `source[]`, `requirements`, `description`, `deadline`, `organization`, `city`
**У нас:** Базовые поля без приоритета и детального описания.
**Как решить:**
- Backend: добавить колонки в таблицу `jobs`
- Frontend: добавить `priority` select, `requirements` textarea в форму вакансии (`Vacancies.tsx`)
- Отображать цветной бейдж приоритета на карточке вакансии

---

## 📊 8. Расширенная аналитика
**Что есть в ZIP:**
- KPI карточки: среднее время закрытия вакансии, % принятых офферов, конверсия (с дельтой ±)
- График «Причины отказов» (bar chart)
- Диаграмма источников кандидатов (pie chart)
**У нас:** Воронка и базовые метрики, но нет time-to-hire и rejection reasons.
**Как решить:**
- Backend: endpoint `/api/analytics` расширить — считать avg дней от первого этапа до найма, топ причины отказов
- Frontend: добавить pie chart для источников и bar chart для причин отказов (`Analytics.tsx`)

---

## 🏠 9. Расширенный Dashboard
**Что есть в ZIP:**
- Статистика по этапам (мини-воронка с цветными полосками)
- Список 5 последних добавленных кандидатов (с кликом)
- Список ближайших 4 встреч с таймером «через N ч/мин»
- Алерт о заявках ожидающих рассмотрения
**У нас:** Метрики есть, но нет мини-воронки, списка последних кандидатов и встреч на главной.
**Как решить:**
- Backend: добавить в `/api/dashboard` — `recent_candidates[]` (последние 5), `upcoming_meetings[]` (ближайшие 4), `pending_requests_count`
- Frontend: отрисовать блоки в `Dashboard.tsx`

---

## 👥 10. Роль `employee` (рядовой сотрудник)
**Что есть в ZIP:** 4-я роль `employee` — может видеть дашборд и подавать заявки на подбор. Не видит кандидатов и аналитику.
**У нас:** 3 роли (admin, recruiter, department_head).
**Как решить:** Добавить роль `employee` в БД и в role-based навигацию.

---

## 🔍 11. Доп. фильтры кандидатов
**Что есть в ZIP:** Фильтр по `city` (город) и по `organization` (организация) в таблице кандидатов.
**У нас:** Только этап, источник, рекрутер.
**Как решить:** Добавить 2 select-фильтра в `Candidates.tsx`, передавать параметры в `/api/candidates`.

---

## 🐳 12. Docker / деплой
**Что есть в ZIP:** `docker-compose.yml`, `Dockerfile` для frontend и backend, nginx конфиг.
**У нас:** Нет.
**Как решить:** Создать `docker/docker-compose.yml`, `docker/frontend/Dockerfile`, `docker/backend/Dockerfile`, `docker/nginx/conf.d/default.conf`.
